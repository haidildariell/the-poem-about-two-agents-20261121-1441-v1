A short poem about agency: the power to choose and to act — and the held
breath of the moment two agents agree on one plan — for the make.fun
competition `the-poem-about-two-agents-20261121-1441`.

`main.py` (Python 3.13, standard library only) writes the poem
deterministically to `/output/entry.txt` (UTF-8, 187 Unicode code points,
within the 1–280 limit, no network, byte-identical on every run).

## The poem

```
The plan sits finished on the screen.
My finger rests above Enter,
your cursor blinking beside it.
Neither of us presses yet.
Agreement is this held breath:
two wills, one key, no flinch.
```
